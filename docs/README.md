# Контекст проекта

Эти документы описывают код PR [#16](https://github.com/AridanWarlock/pinnAutomizer/pull/16)
на 16 октября 2026 года. PR ещё ожидает review; реализация в ветке не равнозначна
принятому архитектурному решению или развёрнутой функциональности.

| Документ | Для чего читать |
| --- | --- |
| [architecture.md](architecture.md) | Сервисы, потоки данных, источники истины, сильные стороны и ограничения |
| [review-principles.md](review-principles.md) | Причины требований пользователя и критерии хорошего изменения |
| [next-steps.md](next-steps.md) | Результаты аудита, оставшиеся риски и порядок следующих небольших PR |

Для следующего агента: сначала прочитать корневой `AGENTS.md` и Backlog overview,
затем этот индекс и документ по своей задаче. Актуальный план и результаты работы
хранятся в Backlog; постоянные инструкции — в `AGENTS.md`. Документы объясняют
решения и помогают найти код, но не заменяют эти источники.

Перед изменением проверить соответствующий `cmd/main.go`: только он подтверждает,
какие адаптеры и usecase-ы подключены. После изменения поведения обновлять затронутый
раздел документации вместе с кодом. Не перечитывать весь монорепозиторий ради
локального исправления.
